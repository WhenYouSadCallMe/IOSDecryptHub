# 阶段 0/1 验收记录

日期：2026-09-18

## 已完成

- 独立 Go 工程 `IOSRuntimeAssistant`。
- Event Schema v1：事件 ID、目标进程、Flow/Request 关联、Native/JS 栈、值引用和敏感级别。
- EventBus：订阅、取消、关闭、context 背压和统计。
- HookSpec/Profile JSON：C 导入、ObjC、Swift 符号、JS、通知类型；重复 ID、目标字段和采样率校验。
- `agent/include/idh_event.h`：原生事件 JSON 传输契约。
- `agent/include/idh_plugin.h`：原生插件生命周期和 ABI 版本契约。
- `core/hook`：通用 Hook Registry，支持注册、批量 profile 安装、启用/停用、卸载和快照。
- `agent/include/idh_hook.h`：原生 Hook Registry C ABI 草案。
- `profiles/generic-network.json`：不绑定业务字段的示例 profile。

- 还没有 iOS/Xcode Agent、fishhook 或 Objective-C 运行时实现。
- Profile 第一版只解析 JSON，YAML 在阶段 12 增加。
- 当前事件总线是进程内实现，桌面持久化和 MCP 在后续阶段实现。
- 未连接真实设备，未读取或写入任何登录态，也未执行短信/下单请求。

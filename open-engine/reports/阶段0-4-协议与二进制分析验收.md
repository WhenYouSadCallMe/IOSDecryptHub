# 阶段 0-4：协议与二进制分析验收

日期：2026-09-18

## 交付

- `core/protocol`：有界识别 JSON、HTTP/1.1、Hex、Base64、Gzip、Zlib、Protobuf wire 和 MessagePack；压缩/编码最多递归两层。
- `core/macho`：解析 thin/FAT Mach-O 的架构、UUID、Segment、虚拟地址和文件范围；提供 runtime/IDA 地址互换。
- `core/stack`：根据明确的 ASLR slide 归一化 native stack，不进行符号执行或目标进程读取。
- MCP 新增 `analyze_payload`、`analyze_macho`、`normalize_stack`。

## 安全边界

- 所有解析都有输入上限，HTTP header 值固定脱敏。
- 解析器只接受已采集的字节或本地文件，不连接目标进程、不执行 Mach-O、不修改请求。
- Protobuf/MessagePack 当前输出 wire/格式提示，不声称已经恢复 schema；后续可由 Profile 插件提供 schema。
